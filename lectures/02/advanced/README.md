# 第2回 発展課題: 用語集SFTと検索の比較

目的は、用語説明の手本によるLoRA学習が回答をどう変えるかを測り、外部の用語集を検索して答える方法と比較することである。結果と考察は [../answer.md](../answer.md) にまとめる。

## 比較条件

| 条件 | モデル | 入力に用語集の本文を含むか |
|---|---|---|
| `base_closedbook` | 学習前のQwen3.5-0.8B | 含まない |
| `sft_closedbook` | 同じモデル＋LoRA | 含まない |
| `search_only` | LLMによる生成なし | 配布の検索関数が定義を返す |
| `base_rag` | 学習前のQwen3.5-0.8B | 検索された最大3件の定義を含む |

生成を行う3条件は、システム指示、モデルrevision、貪欲生成、生成長上限、EOS・PADをそろえる。EOSはtokenizerの会話終端を明示し、SFTTrainerによる自動変更の前後でも同じ値を使う。RAGは共通の指示に検索結果を追加する。検索語は質問文の引用符内の用語、または用語名・別名の最長一致から得る。評価データの正解ラベルを検索語として使わない。

## データと評価

- 配布の `scripts/make_sft_dataset.py` を実行して58語×2問=116件のQ&Aを生成した。
- 学習データに、用語集外の8語について確認を求める手本を2問ずつ追加し、合計132件とした。
- 検証用58件と評価用35問は、学習用と質問文を分けた。用語集外の評価語は、確認要求の学習に用いた8語とも分けた。
- 評価は、用語名を直接尋ねる10問、別名・言い換え10問、用語名を含めない説明5問、用語集外の実在語6問・架空語4問で構成する。
- 同じ用語の定義を学習と評価で共有するため、未学習の用語そのものへの汎化性能を測る設計ではない。
- 用語集内は事前固定した概念語グループの充足、用語集外は記載がない旨の明示・確認要求による回答保留を採点する。語の一致は意味的な正しさの完全な判定ではないため、回答原文も確認する。
- 用語集にない実在語もモデルが事前学習で知っている場合がある。今回は「講座用語集の範囲で答える」という運用方針への適合を測る。

## 再現方法

Google ColabでT4 GPUを選び、[glossary_sft_comparison.ipynb](../../../notebooks/glossary_sft_comparison.ipynb) を上から実行する。ライブラリとモデルの版、データ作成、入力長・分割の検査、4条件の比較、結果保存まで含む。Colabのセッションが切れた場合や再学習する場合はカーネルを再起動する。

データ作成と採点の境界条件のテストはGPU・APIなしで実行できる。

```bash
python scripts/prepare_glossary_experiment.py
python -m unittest discover -s tests -p test_glossary_experiment.py -v
```

## ファイル

| ファイル | 内容 |
|---|---|
| `experiment_plan.md` | 学習前に固定した設計 |
| `dataset_manifest.json` | データ件数、分割の説明、SHA256 |
| `glossary_sft.jsonl` | 配布スクリプトが生成した116件 |
| `train_messages.jsonl` / `valid_messages.jsonl` | 学習・検証用の会話データ |
| `evaluation_gold.jsonl` | 評価質問、正解、概念語の採点基準 |
| `config.json` / `environment.json` | 学習設定、実際のGPU・ライブラリ・入力長 |
| `training.json` | 学習時間、loss、検証loss、ステップ数、ログ |
| `eval_*.json` | 4条件の回答原文、採点、検索語・検索結果の用語名 |
| `comparison.csv` | 同じ質問に対する4条件の回答を横に並べたもの |
| `result.json` | 全条件の要約、改善・退行した質問 |
| `faq_baseline/` | 演習の架空FAQについて別途実行した結果 |

大きなadapter重み・チェックポイントはGitの提出物には含めない。ノートブックから再学習できる。学習時間は `training.json` の `seconds`、各条件の評価時間は要約の `total_seconds` であり、異なる測定値として扱う。

## 評価の限界

1モデル・1seed・35問の小規模実験である。概念語一致には言い換えによる見逃しや、語が含まれていても説明が誤っている可能性がある。検索の説明文質問への弱さは配布の文字列検索に関する結果であり、意味検索全般にそのまま当てはめられない。未知の一般質問への能力や安全性を網羅的に評価したものではない。
